# Quick Notes-AI

AI-powered notes summarizer using Next.js and Node.js that transforms long-form text into concise summaries using LLM APIs. 

## Features

* AI-generated summaries
* Convert long notes into concise text
* Fast and responsive UI
* Loading state handling
* Error handling
* Copy summary button
* Clean modern UI with Tailwind CSS
* Optional dark mode
* Deployable on Vercel

---

## Tech Stack

* **Frontend:** Next.js
* **Backend:** Node.jss
* **Styling:** Tailwind CSS
* **AI:** OpenAI API
* **Deployment:** Vercel

---

## Installation

Clone the repository:

```bash
git clone <your-repo-url>
cd quick-notes-ai
```

Install dependencies:

```bash
npm install
```

Create a `.env.local` file:

```env
OPENAI_API_KEY=your_api_key_here
```

Start the development server:

```bash
npm run dev
```

Open:

```bash
http://localhost:4000
```
